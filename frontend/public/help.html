PRA Rulebook Explorer help

Use the explorer to find rulebook material, inspect its relationships and read the underlying provisions.

Search and navigate

  • Use the search field to find a rulebook part, provision or reporting item.
  • Leave the search field blank to show all rulebook parts.
  • Select a result in the left rail to load its graph and details.

Use the graph

  • Select a node to focus the graph and open its details.
  • Drag the graph to move around it. Use the controls in the lower-right corner to zoom.
  • Open the cog in the lower-left corner to change representation, graph depth, node limits and relationship filters.

Inspect a node

  • The Selected node tab shows the source link, a provision excerpt, Reading mode and Report an issue.
  • The Connections tab shows cross-references, definitions, obligations and other visible relationships.
  • Select a connection to focus that material in the graph.

Use reporting

  • Choose Reporting in the top bar to open the reporting estate graph.
  • Use the reporting search field to find a return, template or topic.
  • Use Estate, Cells and Impact to move between the reporting graph, workbook cells and change analysis.
  • Use the view options menu to include superseded editions.

Read a provision

  • Select Reading mode in the node details to open the source text.
  • Select an inline reference to inspect the linked material.
  • Use the reference shelf to keep related provisions available while you read.
